# 薪酬测算 App 产品设计文档

## 1. 文档信息

- 产品名称：薪酬测算
- 文档类型：产品设计文档
- 目标平台：iOS、Android
- 产品阶段：MVP
- 依据文档：[薪酬计算.md](薪酬计算.md)
- 配套研发文档：[薪酬测算Flutter研发实现文档.md](薪酬测算Flutter研发实现文档.md)

## 2. 产品概述

薪酬测算 App 帮助个人快速理解一份月薪在扣除个人社保、公积金和个税后能获得多少现金，以及单位和个人共同缴纳的部分形成多少长期权益。首版采用单页计算器，预置一组可编辑的默认参数，修改参数后即时展示月度和全年结果。

本产品用于方案比较和薪酬估算，不替代正式工资单、个税申报或地区社保核算。结果以用户输入和本产品列明的简化费率为依据。

## 3. 用户与主要场景

### 3.1 目标用户

- 求职者：比较税前工资与实际到手、单位总成本和长期权益。
- 在职员工：估算工资、专项附加扣除或社保基数变化的影响。
- 招聘人员及 HR：用统一的假设快速解释不同税前薪资方案。

### 3.2 主要场景

1. 用户打开应用，查看默认税前工资 33,000 元对应的全年测算。
2. 用户调整工资、专项附加扣除、社保基数或公积金比例，查看结果变化。
3. 用户查看某个月的税后现金和权益，并理解累计预扣造成的月度变化。
4. 用户展开计算依据，核对单位缴费、个人扣款、税率档位和权益构成。

## 4. MVP 产品目标与范围

### 4.1 产品目标

- 默认参数开箱即用，无需注册或联网。
- 所有主要参数可见、可修改，结果变更及时反馈。
- 同屏展示单位成本、税后现金、权益 A、权益 B。
- 提供全年累计预扣明细和可读的计算拆解。
- 可保存当前参数及结果快照，并通过历史列表回看。
- 33,000 元默认方案与《薪酬计算.md》的演示结果相符。

### 4.2 首版包含

- 单一薪酬方案、固定月薪、12 个月在职。
- 工资、专项附加扣除、社保基数、公积金基数、公积金比例和工伤保险费率的编辑。
- 默认参数恢复、本地保存、离线计算；保存历史快照、历史列表、结果概览以及单条/全部删除。
- 月度和全年汇总、月度个税明细、权益组成说明。

### 4.3 首版不包含

- 多方案管理、方案对比、登录、云同步。
- 年中调薪、奖金单独计税、入职或离职月份。
- 地区费率模板、社保上下限自动校验、各险种独立基数。
- 逐项专项附加扣除管理、报税或正式工资单功能。
- PDF、Excel 导出和企业批量导入。

## 5. 参数与默认值

| 参数 | 默认值 | 用户是否可编辑 | 说明 |
|---|---:|---|---|
| 月税前工资 A | 33,000 元 | 是 | 固定月薪；默认作为跟随工资的社保基数 |
| 月专项附加扣除 E | 5,000 元 | 是 | 默认演示拆分：子女教育 2,000 + 赡养老人（非独生子女）1,500 + 住房租金 1,500；按满足各项条件的示例情景计算，详见算法说明 |
| 月社保基数 S | 跟随 A，初始为 33,000 元 | 是 | 跟随工资时随 A 自动变更；手动编辑后转为自定义 |
| 公积金比例 r | 12% | 是 | 单位和个人采用同一比例 |
| 公积金基数模式 H | 跟随社保基数 S | 是 | 社保基数跟随工资或自定义时，公积金基数均跟随当前 S；也可切换为独立自定义 |
| 工伤保险费率 w | 0.2% | 是 | 单位承担；默认值用于演示，可按本单位核定费率填写 |
| 基本减除费用 | 5,000 元/月 | 否 | 按本产品所依据的计算文档固定 |
| 个人大病统筹 | 3 元/月 | 否 | 按本产品所依据的计算文档固定 |

养老单位 16%、个人 8%；医疗单位 9.8%、个人 2%；失业单位和个人均为 0.5%。工伤保险仅由单位缴纳，默认费率 0.2%，用户可自定义。国家工伤保险实行行业差别费率和单位浮动费率，具体值以当地经办机构核定为准。

## 6. 结果定义与业务规则

### 6.1 缴费组成

社保缴费使用用户设置的社保基数 S。公积金缴费使用独立的基数 H，默认跟随当前社保基数 S；用户可切换到自定义模式。实际公积金基数通常按本人上一年度月平均工资及当地年度上下限核定，和社保基数不必相同。

- 单位社保 = S × (26.3% + w)，其中 w 为可编辑的工伤保险费率，默认 0.2%。
- 个人社保 = S × 10.5%。
- 单位公积金 = H × r。
- 个人公积金 = H × r。
- 个人扣款合计 = 个人社保 + 个人公积金 + 3 元大病统筹。

工伤保险仅由单位缴纳。失业保险和大病统筹不计入个人账户权益。

### 6.2 个税

当月新增应纳税所得额 = max(0，A - 个人扣款合计 - 5,000 元基本减除费用 - E)。

个税采用累计预扣法：累计应纳税所得额是本年度各月新增应纳税所得额之和；累计应纳税额按累计税率表计算；当月预扣个税为累计应纳税额扣除本年此前已预缴个税后的金额，最低为 0。

首版采用《薪酬计算.md》的累计预扣率和速算扣除数：

| 累计应纳税所得额 | 预扣率 | 速算扣除数 |
|---:|---:|---:|
| 不超过 36,000 元 | 3% | 0 元 |
| 超过 36,000 至 144,000 元 | 10% | 2,520 元 |
| 超过 144,000 至 300,000 元 | 20% | 16,920 元 |
| 超过 300,000 至 420,000 元 | 25% | 31,920 元 |
| 超过 420,000 至 660,000 元 | 30% | 52,920 元 |
| 超过 660,000 至 960,000 元 | 35% | 85,920 元 |
| 超过 960,000 元 | 45% | 181,920 元 |

### 6.3 四项核心指标

| 指标 | 月度计算 | 全年计算 |
|---|---|---|
| 单位成本 | A + 单位社保 + 单位公积金 | 12 个月单位成本之和 |
| 税后现金 | A - 个人扣款合计 - 当月预扣个税 | 12 个月税后现金之和 |
| 权益 A | 税后现金 + 单位公积金 + 个人公积金 + 个人医疗缴费金额 | 12 个月权益 A 之和 |
| 权益 B | 权益 A + 个人养老缴费金额 | 12 个月权益 B 之和 |

权益 A、权益 B 是便于比较的测算口径，不代表全部金额都可立即支取。养老保险个人账户流动性较低；个人医保及公积金的实际使用、提取受政策和个人账户规则影响。

### 6.4 33,000 元默认方案的演示基准

默认参数为 A = S = 33,000 元、E = 5,000 元、r = 12%。结果页默认打开“全年”视图：

| 指标 | 结果 |
|---|---:|
| 单位月成本 | 45,705 元 |
| 全年累计应纳税所得额 | 186,864 元 |
| 全年个税 | 20,452.80 元 |
| 全年税后现金 | 286,411.20 元 |
| 全年权益 A | 389,371.20 元 |
| 全年权益 B | 421,051.20 元 |

月度演示数据：

| 月份 | 当月个税 | 税后现金 | 权益 A | 权益 B |
|---|---:|---:|---:|---:|
| 1–2 月 | 467.16 元 | 25,104.84 元 | 33,684.84 元 | 36,324.84 元 |
| 3 月 | 1,217.28 元 | 24,354.72 元 | 32,934.72 元 | 35,574.72 元 |
| 4–9 月 | 1,557.20 元/月 | 24,014.80 元/月 | 32,594.80 元/月 | 35,234.80 元/月 |
| 10 月 | 2,729.20 元 | 22,842.80 元 | 31,422.80 元 | 34,062.80 元 |

3 月累计应纳税所得额跨入 10% 档，10 月跨入 20% 档。全年金额为月度结果求和。

## 7. 信息架构与页面设计

### 7.1 页面结构

MVP 以单页计算器为主，另提供历史列表和结果概览辅助页：

1. 顶部：产品名称、默认值恢复入口。
2. 参数区：税前工资、专项附加扣除、社保基数、公积金基数、公积金比例和工伤费率；可保存本次测算并进入历史列表。
3. 结果区：单位成本、税后现金、权益 A、权益 B 四张指标卡。
4. 结果范围切换：全年 / 月度；月度模式提供 1–12 月选择器。
5. 月度拆解卡片：默认折叠，显示全年或当前所选月份的预览；展开后列出 12 个月的个税、到手现金、权益 A、权益 B 和税档。
6. 计算依据：可展开查看单位和个人缴费、累计应税收入、税率及权益构成。
7. 说明区：测算口径、地区差异和非正式工资单提示。

历史列表和结果概览通过计算器页面按钮进入。列表按保存时间倒序展示工资、社保和公积金基数及全年税后现金；点击记录打开只读的结果概览页。每项支持单条删除，列表提供清空全部操作，两种删除均需用户确认。

### 7.2 首屏层级

首屏优先展示全年四项指标，参数区保留足够显著的编辑入口。纵向滚动后可查看月度拆解和完整计算依据。月度拆解默认收起，全年模式显示 12 个月预览提示，月度模式显示所选月份的税档和税后现金；展开后查看完整逐月列表。小屏设备上结果卡片使用两列布局；窄屏可改为单列。

### 7.3 参数交互

- 金额字段使用人民币键盘，编辑状态不插入无法删除的千分位分隔符。
- 点击页面空白区域时收起键盘；点按输入框继续编辑。
- 失焦或提交后按千分位格式展示，内部以分或定点金额保存。
- 社保基数提供“跟随工资”状态和“自定义”状态；编辑基数即切换为自定义。
- 公积金比例使用百分比输入。单位和个人缴费金额随比例同时更新。
- 公积金缴存基数独立提供“跟随社保基数”和“自定义”两种状态；默认跟随当前社保基数，自定义后不随工资或社保基数变化，并始终显示当前值及联动来源。
- 公积金基数标题旁的信息按钮预览国家基数规则，包括上一年度月平均工资、新入职/调入职工口径和 3,500 元基数示例；官方链接可跳转外部浏览器。
- “保存本次”保存当前有效输入和对应计算结果快照；无效输入草稿时禁用。历史列表可查看保存时间和主要参数，记录可打开结果概览页；支持确认后删除单条或清空全部记录。
- 工伤保险费率使用百分比输入，由单位承担；默认 0.2%，可按本单位核定费率调整。
- 专项附加扣除、公积金比例和工伤保险费率标题旁显示信息按钮；点按后在弹窗中预览对应 Markdown 国家规则，官方链接可跳转外部浏览器。
- 四份规则文档分别列出专项附加扣除类别与填报示例、公积金比例范围、公积金基数口径、工伤行业基准费率及浮动说明，并提示以本人资格和当地核定为准。
- 任一有效参数变化后立即刷新结果，无需单独点击计算。
- “恢复默认”重置所有可编辑参数，并将社保基数与公积金基数模式恢复为默认联动；执行前提供确认。

### 7.4 结果交互

- 全年视图显示四项年度总和；月度拆解卡片可折叠或展开，折叠时显示全年预览，展开后提供 12 个月的逐月明细。
- 月度视图显示选定月份四项指标和当月个税；折叠的月度拆解卡片预览所选月份，展开后仍可查看完整逐月列表，点击月份即可切换结果。
- 当累计应纳税所得额跨档时，在该月标记“进入 X% 档”，并可在计算依据解释变化来源。
- 点击权益 A 或权益 B 查看组成；权益 B 中的个人养老账户单独标出。
- 当社保基数不是工资全额时，在结果附近显示“自定义社保基数”提示。

## 8. 校验、提示和异常状态

| 场景 | 产品处理 |
|---|---|
| 工资、扣除额或任一缴费基数为空 | 编辑时允许暂留；完成编辑后显示字段错误并暂停结果更新，标明当前结果对应上次有效参数 |
| 金额为负数 | 不接受，显示字段级提示 |
| 公积金比例或工伤费率非法 | 只接受 0%–100% 的数值，最多两位小数，显示百分比格式 |
| 应纳税所得额低于 0 | 按 0 处理，并说明本月未增加应税所得额 |
| 社保基数高于或低于工资 | 允许自定义，不做地区上下限推断；展示自定义提示 |
| 本地存储读取失败 | 使用默认参数启动，并允许用户继续使用 |
| 无网络 | 不影响计算和已保存参数读取 |

## 9. 产品体验与隐私要求

- 默认参数和计算规则可离线使用，不要求登录。
- 用户薪酬参数、历史测算快照默认只保存在设备本地。
- 不将工资、扣除额或计算结果写入日志或崩溃上报。
- 支持系统字号放大、屏幕阅读标签、足够的文本对比度和深色模式。
- 结果页固定提示“测算结果”，并说明地区缴费上限、实际工资结构及年度汇算可能造成差异。

## 10. 产品验收标准

- 首次打开即显示 33,000 元默认工资、5,000 元专项附加扣除、12% 公积金比例及跟随工资的社保基数。
- 工资、扣除额、缴费比例、社保基数、公积金基数和工伤费率均可编辑；编辑后核心指标和逐月税额即时刷新。
- 用户能切换全年和任一月份，看到单位成本、税后现金、权益 A、权益 B。
- 四个规则信息按钮均打开正确的规则弹窗；Markdown 中的官方链接可打开。
- 公积金基数默认跟随社保基数；社保基数切换工资/自定义后联动金额正确，自定义公积金基数不再联动，结果拆解显示基数和来源。
- 有效测算可保存为历史快照；保存后从历史列表打开的结果概览与原保存参数一致，不随当前输入变化。
- 历史记录按时间倒序显示，单条删除和清空全部均有确认步骤；删除后列表状态与本地存储一致。
- 工伤保险费率默认 0.2%，用户修改后单位缴费和单位总成本即时更新；个人扣款不受影响。
- 月度拆解卡片支持折叠和展开；折叠态按当前结果模式显示预览，展开态列出 12 个月并支持点选月份。
- 默认方案四项全年结果符合第 6.4 节，逐月税档变化符合演示数据。
- 计算依据能解释个人与单位缴费、累计预扣税额、权益组成。
- 个人医保进入权益 A；个人养老账户只额外进入权益 B。
- 恢复默认、当前参数本地保存和历史快照管理可用，离线状态下功能完整。
- 页面明确区分测算结果与正式工资单。

## 11. 口径说明与已知边界

《薪酬计算.md》的速查表中“月扣五险一金”一列给出的 25,572 元，是税前工资扣除个人缴费后的计税前余额，不是个人缴费金额。产品界面和研发实现均应将其拆分显示，避免重复扣除。

首版按同一社保基数计算养老、医疗、失业、工伤缴费；公积金基数默认跟随当前社保基数，也允许单独自定义。实际城市可能对险种基数、公积金基数、费率、缴费上限和个人医保账户入账比例有不同规定，当前产品不推断或覆盖这些地区规则。
