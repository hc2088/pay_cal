# 薪酬测算速记手册

> **口径**：月专项附加扣除示例 5,000 元（子女教育 2,000 + 赡养老人（非独生子女）1,500 + 住房租金 1,500）。这是按满足各项条件的情景拆分，租金按 1,500 元档计算；实际金额按资格、分摊方式和城市标准填写。
> **费率**：以下公司成本公式按工伤费率默认值 0.2% 计算；工伤费率可在应用中调整。单位合计 38.5%；个人 22.5% + 大病固定 3 元

## 一、费率口径

| 险种 | 单位 | 个人 |
| --- | ---: | ---: |
| 养老保险 | 16% | 8% |
| 医疗保险 | 9.8% | 2% |
| 失业保险 | 0.5% | 0.5% |
| 工伤保险 | 默认 0.2%（可自定义） | — |
| 住房公积金 | 12% | 12% |
| 大病统筹 | — | 3 元 |
| **合计** | **38.5%（按默认工伤费率）** | **22.5% + 3 元** |

> 工伤全部由单位承担，个人不缴。

## 二、核心公式（税前工资 = a）

| # | 项目 | 公式 |
| --- | --- | --- |
| 1 | 公司月总成本 | `a × (1 + 16% + 9.8% + 0.5% + 工伤费率 + 12%)`；默认费率下为 `1.385a` |
| 2 | 月扣五险一金大病 | `0.775a − 3` |
| 3 | 当月新增应纳税所得额 T | `0.775a − 10003` |
| 4 | 累计预扣个税 | `累计T × 预扣率 − 年度速算扣除数` |
| 5 | 当月应交个税 | `累计预扣个税 − 本年已预缴` |
| 6 | 到手现金 | `(0.775a − 3) − 当月个税` |
| 7 | 综合到手（不含养老个人账户） | `现金 + 0.26a`（双边公积金 0.24a + 医保个人 0.02a） |
| 8 | 综合到手 + 养老（含养老个人账户） | `现金 + 0.34a`（综合到手部分 0.26a + 个人养老 0.08a） |

> T ≤ 0 时当月无个税，累计 T 不增加。`10003 = 起征点 5000 + 专项附加 5000 + 大病 3`。

## 四、速算扣除数

速算扣除数 = 全额按高档税率算出的税额 − 真实分级累加的税额，是一个补差常数。

以 10% 档为例：前 36,000 按 3% 交 1,080，超出部分按 10%，即 `0.1T − 2,520`，速扣 = 2,520。

> 月度速扣 = 年度速扣 ÷ 12（如 2,520 ÷ 12 = 210），仅用于粗估。
> 真实个税为**累计预扣**，跨档当月税额会跳涨，年初低、年末高。

## 六、备注

1. 真实口径为**累计预扣**，跳档属正常现象；月度简化表只适合粗略比较。
2. 养老个人账户退休后方可支取，流动性弱；公积金可按政策提取。
3. 失业、大病属保障性支出，无个人账户余额；工伤全部由单位缴纳，均不计入个人权益。
4. 次年 3–6 月汇算清缴，多退少补。
5. 若改为**无专项附加扣除**：`当月新增 T = 0.775a − 5003`，其余公式不变。公司成本公式中的工伤费率按输入值调整，默认示例为 0.2%。
