# 住房公积金缴存基数规则

## 国家规则如何确定基数

《住房公积金管理条例》第十六条规定，职工和单位每月缴存额分别按职工本人上一年度月平均工资，乘以职工和单位各自的缴存比例计算。第十七条另有新参加工作、新调入职工的起缴月份和基数规定：新参加工作的职工从参加工作的第二个月起缴存，基数按本人当月工资；单位新调入职工从调入单位发放工资之日起缴存，基数按本人当月工资。

各地住房公积金管理中心会按年度公布本地缴存基数上下限和办理口径。通常应以规定口径核定的工资为基数，并在当地上下限内执行；不能只因为某个较低金额等于当地最低工资，就当然把缴存基数定为该金额。

## 和社保缴费基数是不是同一个

国家规则没有要求住房公积金基数必须与社保缴费基数相同。两者的工资口径、核定周期和本地上下限可能不同，因此实际金额可能相同，也可能不同。公积金基数通常参考上一年度月平均工资；社保基数也受当地社保年度申报规则影响，不能仅凭一个输入值推断另一个输入值。

为了让测算口径清楚，本应用**默认让公积金基数跟随当前社保基数**：

- 社保基数选择“跟随工资”时，公积金基数随当前税前工资对应的社保基数变化。
- 社保基数选择“自定义”时，公积金基数随自定义社保基数变化。
- 选择“自定义”公积金基数后，两者分开计算；之后修改社保基数不会改变自定义的公积金基数。

页面会显示公积金基数当前是“跟随社保基数”还是“自定义”，并显示采用的金额。若知道工资单或公积金账户中的实际缴存基数，可选择自定义并输入该金额。

## 3,500 元基数和 175 元个人缴存额

若个人缴存比例为 5%，以 3,500 元为基数，个人月缴存额的计算确为 `3,500 × 5% = 175 元`。但这只能说明乘法结果，不能单凭这个金额判断缴存合规与否。

如果上一年度月平均工资约为 6,920 元，且不是新参加工作或新调入等特殊情形，应进一步核对单位使用 3,500 元基数的依据，以及该地区当年的上下限和办理规则。若单位没有符合规定的核定依据，按明显低于应核定工资的基数缴存，可能造成少缴；建议向单位人事或当地住房公积金管理中心确认。全国规则不支持把 3,500 元一概视为统一合法基数，也不能只因社保基数为 6,920 元就直接判定公积金基数违法。

本应用允许单独输入公积金基数，以便复现工资单和不同场景；不会自动核验当地上下限、个人上一年度平均工资或缴存合规性。测算时请优先使用工资单、单位缴存通知或公积金账户记录中的实际基数。

## 计算方式

```text
单位月缴存额 = 公积金缴存基数 × 单位缴存比例
个人月缴存额 = 公积金缴存基数 × 个人缴存比例
```

## 官方规则

- [住房公积金管理条例（住房和城乡建设部）](https://www.mohurd.gov.cn/gongkai/fdzdgknr/zfhcxjsbwj/gkzhudongfalvfagui/gkzhudongfagui/art/2019/art_18379_240516.html)：第十六条规定上一年度月平均工资的基数口径；第十七条规定新参加工作、新调入职工的起缴及基数口径。
- 各地基数上下限和办理口径请查询缴存地住房公积金管理中心当年度公告；国家条例没有给出适用于所有城市的统一金额上下限。
