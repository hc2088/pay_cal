# 工伤保险费率规则

## 国家行业基准费率

工伤保险由用人单位缴纳，职工个人不缴。国家按行业工伤风险类别设置一类至八类基准费率，分别约为：

| 行业风险类别 | 全国行业基准费率 |
| --- | ---: |
| 一类 | 0.2% |
| 二类 | 0.4% |
| 三类 | 0.7% |
| 四类 | 0.9% |
| 五类 | 1.1% |
| 六类 | 1.3% |
| 七类 | 1.6% |
| 八类 | 1.9% |

这些是全国行业基准费率的控制标准，不等于每家单位最终实际缴费率。统筹地区会制定当地具体标准，并根据单位工伤保险基金使用、工伤发生率、职业病危害程度等因素实行浮动；不同行业、地区和浮动档次的单位可能不同。

本应用默认 **0.2%**，与国家一类行业基准费率数值相同，仅作演示起点，不代表本单位属于一类行业或应按此缴费。请优先填写工资单、单位缴费通知或当地社保经办机构核定的本单位费率。应用按页面社保缴费基数乘以该费率估算单位工伤缴费，不会自动判断行业分类、地区标准或浮动档次。

## 计算方式

```text
单位月工伤保险费 = 工伤保险缴费基数 × 本单位核定费率
```
