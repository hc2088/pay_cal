候选数据包括历史口径与推导值。所有城市 `releaseReady = false`；目前只有北京、上海部分字段完成独立官方核验，完整年度正式规则包尚未完成。数据文件未接入 Flutter，不能直接作为生产默认参数发布。

空值表示未知，不表示 0。不从上游年度标签推导生效日期；公积金候选上限与产品预选单独存储；工伤 0–0 候选边界已转换为 null。省直管县、兵团和其他独立统筹区等覆盖缺口见 JSON 顶层 `coverage`。
